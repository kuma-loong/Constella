## 隐私审核

此前已扫描源码、候选包及所有引用可达的 1,159 个历史 Git blob。未发现真实密钥，当前生产令牌与身份配置字面量比对无命中。
历史扫描的 2,603 个高熵命中均为依赖校验和；其他旧分支的 19 个历史 blob 含本机用户名路径，不在本次发布祖先链中，未重写这些旧分支。
已人工检查 8 张文档 PNG 和两个 GIF 的首、中、尾帧，未发现私人内容；GIF 并未逐帧检查。
原始证据保留在本地 `run/preview-release-0.1.5/`，该目录名称仅表示此前审核批次。
新版候选包另行检查文件清单、密钥及生产配置字面量，不包含数据库、日志、运行配置或令牌文件。
这些是明确范围内的扫描和复核结果，不是对未知秘密的绝对保证。
